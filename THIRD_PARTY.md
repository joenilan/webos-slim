# Source provenance

`launcher/` derives from gprot42/webos-launch-home:
https://github.com/gprot42/webos-launch-home

Its MIT license and upstream copyright are retained in `launcher/LICENSE`.
This snapshot includes the locally developed GPUI dashboard, native Home
routing, widgets, startup/launch feedback and voice-assistant removal through
0.0.133. Public defaults/fixtures omit the owner's location and LAN address.
The existing private working checkout was preserved.

The launcher font license is retained at `launcher/assets/fonts/Inter-LICENSE.txt`.
Background/remote-asset sources are documented in
`launcher/docs/background-sources.md`. Existing upstream assets and source
remain subject to their respective notices. The repository's own code and
original documentation use the root MIT license.

LG firmware files, dumps, QML and decompiled native output are not distributed
or relicensed by this project. Experiments operate on private owner-supplied
inputs. REA, Ghidra, Homebrew Channel and the webOS packaging CLI are separate
tools with their own licenses.
